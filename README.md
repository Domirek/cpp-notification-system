# C++ Notification System (учебный проект)

Данный проект демонстрирует основы объектно-ориентированного программирования в C++ на примере простой системы уведомлений.

## Описание

В системе есть абстрактный класс `INotifier`, который определяет интерфейс для отправки уведомлений. От него наследуются три конкретных класса:

- `EmailNotifier` – отправка по электронной почте (хранит SMTP‑сервер)
- `SmsNotifier` – отправка SMS (хранит имя провайдера)
- `PushNotifier` – отправка push‑уведомлений (хранит имя приложения)

Каждый класс реализует метод `send()`, который выводит информацию о доставке в консоль.

## Ключевые особенности кода

- **Виртуальный деструктор** в интерфейсе – обеспечивает корректное удаление объектов через указатель на базу.
- **Чисто виртуальная функция `send`** – делает класс `INotifier` абстрактным (интерфейсом).
- **Ключевое слово `override`** – явно указывает на переопределение виртуального метода, защищая от ошибок в сигнатуре.
- **`explicit` конструкторы** – предотвращают неявные преобразования при создании объектов.
- **Умные указатели `std::unique_ptr`** – автоматически управляют временем жизни объектов, исключая утечки памяти.
- **Контейнер `std::vector`** – хранит различные типы уведомителей единообразно благодаря полиморфизму.
- **Функция `NotifyUser`** – принимает ссылку на интерфейс и работает с любым наследником.
